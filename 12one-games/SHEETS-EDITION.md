# Sheets edition

The four v3 entrypoints now load the interactive GitHub Pages client from `12one-games/sheets-v3/` rather than the old launcher. The old launcher is retained on this development branch but no longer referenced by the new pages.

Read [installation instructions](sheets-v3/README.md), [feature-parity checklist](sheets-v3/PARITY.md), and [test results](sheets-v3/TEST-RESULTS.md). This remains a development candidate; do not deploy to real participants or merge until the release gates are satisfied.
